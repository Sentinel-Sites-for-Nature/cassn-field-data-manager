# Welcome photography

Three original camera-trap JPEGs curated by John, copied unchanged into the
repository on 2026-10-23. The fixed order is ringtail, cougar, squirrel.

Every installation uses these bundled repository assets. There is no local
photo-folder override or user-facing photo replacement control. John maintains
this set in the repository and distributes changes with new app releases.

To release new photos, replace the assets here and update DEFAULT_PHOTOS in
cassn/gui/welcome_photos.py for the desired order and focal points, then rebuild
the app. Display-only crops keep the animals visible and omit timestamp strips
where present. Original image files are not modified by the app.
